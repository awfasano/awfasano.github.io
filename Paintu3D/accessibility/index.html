Accessibility

Paintu3D accessibility notes

Paintu3D includes adjustable input and visual settings for a more comfortable spatial painting experience.

Current interaction support

  • Choose a dominant drawing hand and use either a pinch or extended-index drawing gesture.
  • Adjust hand smoothing to balance jitter reduction and fast-stroke responsiveness.
  • Use the separate controls window with the non-drawing hand while painting.
  • Reduce Visual Effects lowers the intensity of high-luminance cosmic and neon brushes.
  • Recenter controls restore spatial work if its placement becomes uncomfortable or hard to reach.
  • Standard SwiftUI controls include accessibility labels and system focus behavior throughout the library and settings.

Spatial input

Painting gestures depend on tracked hand movement or a supported spatial input device. Controls for creating, saving, exporting, retrying, and recentering remain available in standard windows. Accessibility support may vary by painting mode because freehand spatial drawing requires three-dimensional pointing.
